# 来源与两层设计

## 人物层

来自已有 `panjie-perspective` v1.1，人物材料截至 2026-09-14。公开版保留工作场景的三个核心判断、直接而具体的口语，以及人物自述、整理归纳和新情境推演之间的区别。

公开版是选编，不代表完整人格研究。原始私人访谈、私生活细节、完整题号证据档案和公司内部资料没有随仓库公开。需要核对未收录的原话时，不能声称本仓库保存了原件。

## 应用层

来自分享版的任务使用方式，并针对公开分发优化：客户分析、方案比较、口播和回复都能通过统一入口完成。应用层的流程是整理建议，不能替人物层增添本人观点。

## 平台层

标准包与 WorkBuddy 包使用同一人物正文、应用正文和参考文件。WorkBuddy 包增加官方规定的中英文简介、版本、作者等元数据与资源提示；标准包保留通用的 `name` 与 `description`，并附 Codex 界面配置。

单文件提示词合并同一套正文，供不能读取技能文件夹的工具使用。生成过程不访问原始知识库或维护者电脑的外部目录。

## 内容优先级

本次用户的明确事实与修正应记录适用范围；人物层决定怎样模拟，应用层负责怎样完成任务。新的业务资料可以更新本次事实背景，但不能自动改写人物模型。技术适配不改变人物含义。

方法参考：花叔的 [女娲 · Skill 造人术](https://github.com/alchaincyf/nuwa-skill)。本仓库没有复制其整套研究资料或第三方人物示例库。
