# 客户沟通框架

这是适合公开使用的需求分析方法，依据既有研究框架重新选编。不附评论原文、用户标识、企业经营数据或真实案例；这些组合没有统计占比，也不是对某个客户的事实判断。

## 先了解他要改变什么

人们可能想增收、让手艺得到回报、改变生活、安排家庭、学习或为长期发展增加选择。这些目标可以并存，由当事人排序。

理解一个人的单位可以是：**当前处境、主要目标、现有条件、所处阶段、停止条件。**不要凭年龄、昵称、职业名称或一条评论推断全部人生处境。

## 四组关键区别

| 主题 | 分开了解的事情 |
| --- | --- |
| 钱 | 报价、可用现金、资金证明、生活开销、已付款与备用钱；谁能动用、什么时候到账 |
| 技能与语言 | 年限、具体工具和工艺、独立完成的任务、现有证书、实际交流与考试结果 |
| 家庭 | 谁同行、谁留下、谁工作、谁照护；不同步成行时怎么安排 |
| 信任与选择 | 想看哪些证据、怎么知道进展、能等多久、什么情况愿意停止 |

## 别把阶段混在一起

有意愿、已联系、开始准备、已付款、递交、获批、已有岗位、入职与稳定收到收入，是不同状态。暂停、换工作、改变路线和退出，也不能统称为失败。

分析时问清“现在已经发生什么”，再讨论下一步；不要把计划写成已经完成的事实。

## 咨询时怎么推进

先回答对方最在意的事，再补真正影响判断的两三项条件。进入具体方案后，才对照相应岗位、服务、费用和责任材料。

每次可以留下一个明确的下一步，例如整理近期实际工作内容、列出费用分项、把家里最担心的事情说清楚。未知项留空，不一次要求提供所有私人信息。

## 可用选题

- 同样叫木工，具体做的活有什么差别？
- 工资数字之外，哪些事情影响真正的结余？
- 家里担心时，应该先把哪几件事讲清楚？
- 正在学英语，怎样说明自己的准备进度？
- 想暂停时，怎样分清原因与后续安排？

这些是内容方向，不是热度排名、成交结论或个案证明。需要人物故事时，明确使用假设，或依据当次用户提供且可引用的真实材料。
